The previous version of this site was a Create React App build with forty hand-written project pages, a hash router, and an images folder that had been deleted from git. It did not compile. That is a bad place for a portfolio to be.

## What changed

- **Astro instead of CRA.** Static output, near-zero JavaScript, built-in sitemap and RSS.
- **One template, not forty pages.** Every project is now an MDX file in a content collection. Add a file, get a page.
- **Bilingual.** English and Turkish, side by side, with a language switch that keeps you on the same page.
- **Themeable.** Light and dark, system-aware, no flash on load.

## What stayed

The space theme — but quieter. One accent colour, a faint nebula, and a lot more whitespace.
