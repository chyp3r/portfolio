# First-run checklist

The rebuild is done in the working tree. It is **not committed** and dependencies
are **not installed** (no npm on this machine at build time). Run these steps.

## 1. Install & run locally

```bash
npm install
```

```bash
npm run dev
```

Open http://localhost:4321 — and http://localhost:4321/tr/ for Turkish.
Then verify a production build:

```bash
npm run build && npm run preview
```

`npm run build` should finish with no errors and produce `dist/` containing
`sitemap-index.xml`, `rss.xml`, and `projects/<slug>/index.html` for every project
in both languages.

## 2. Optional content you provide

- **CV** — drop a PDF at `public/cv.pdf`. The "Download CV" button in the hero
  appears automatically once the file exists (it HEAD-checks at runtime).
- **Better images** — replace files in `src/assets/media/`. The current set was
  recovered from git history (`d95cdc3^`), where the original `src/assets/images/`
  tree still had its real folder structure — so covers and galleries are mapped
  correctly. Galleries exist for Vitabyte, Hocus Focus, Enyaroyis, ASCLEPIUS
  2023/2024, Career Fair, Quantum Shift and Alzcur. Only **ODAK** and **Filmora**
  gallery shots are missing — those images were never committed (build-only) and
  the flattened build filenames were ambiguous. Their covers are fine.
- **OG image** — `public/og-default.jpg` is a recovered nebula image; swap it for
  a branded 1200×630 card if you want.

## 3. Move the repo to a user site

The config targets `https://chyp3r.github.io` with `base: '/'`.

1. On GitHub, rename the repo `chyp3r/portfolio` → `chyp3r/chyp3r.github.io`
   (Settings → General → Repository name). The `origin` remote updates automatically
   on GitHub's side; update your local remote:
   ```bash
   git remote set-url origin https://github.com/chyp3r/chyp3r.github.io.git
   ```
2. Move work onto `main` (the old default branch is `gh-pages`):
   ```bash
   git checkout -b main
   ```
3. Commit and push:
   ```bash
   git add -A
   git commit -m "Rebuild portfolio on Astro (bilingual, 2026)"
   git push -u origin main
   ```
4. Repo **Settings → Pages → Build and deployment → Source → GitHub Actions**.
5. The `Deploy to GitHub Pages` workflow runs on every push to `main`.

> Staying on a project page instead? Set `base: '/portfolio'` in `astro.config.mjs`,
> keep `site: 'https://chyp3r.github.io'`, and deploy from a `portfolio` repo. All
> internal links already go through `localizePath()` / `BASE_URL`, so they adapt.

## 4. Custom domain (later, optional)

Add `public/CNAME` with the domain, set `site` to `https://yourdomain.com`,
`base` to `'/'`, and point DNS at GitHub Pages.
